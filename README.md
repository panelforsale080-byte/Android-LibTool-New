# Android LibTool (Axcel Modified tools)

Native Android mod menu for **authorized** IL2CPP / Unity testing on apps and devices you own or have permission to inspect.

**Version:** 3.4.1

## Download APK (public)

**Direct link:** https://github.com/panelforsale080-byte/Android-LibTool-New/releases/download/v3.4.1/app-debug.apk

**Release page:** https://github.com/panelforsale080-byte/Android-LibTool-New/releases/tag/v3.4.1

> arm64-v8a debug APK (modern 64-bit phones). Delete the GitHub repo/release when you no longer need it.

## What's new in v3.4.1

- **Runtime trace fix** — Stalker `trust_threshold = -1` (was 0, which disabled instrumentation immediately)
- **Target-only stalking** — excludes all other modules so only the selected `.so` is instrumented
- Fresh module base refresh before trace start; callout diagnostic counter in UI

## What's new in v3.4.0

- **Full runtime instruction trace** — Frida Stalker counts every executed instruction in the selected `.so` (all threads)
- **Per-offset hit table** — e.g. `+0x123455 sub sp, sp, #0x80 → 80 hits`
- **Export trace CSV** — `offset,mnemonic,hits` to app files folder
- Replaces the old Dobby entry-point call log

## What's new in v3.3.2

- **IDA-style `.lst` disassembler** — full executable segment listing saved to file (Capstone, file-backed reads)
- **Expanded So Monitor** — hooks dynsym exports **plus** statically discovered in-module BL branch targets
- **UI updates** — `.lst` default filename, clearer monitor/disasm status text

## What's new in v3.3

- **Phone-first menu layout** — window auto-centers and sizes to ~96% width / ~90% height on small screens
- **Auto UI scale** — picks Tiny → XL preset from screen size on first launch
- **Scrollable tab bar** — tabs no longer scramble/overlap on narrow phones (`FittingPolicyScroll` + overflow popup)
- **FPS counter** — top-right overlay (toggle in **Settings → Show FPS counter**)
- **Auto-fit button** — **Settings → Auto-fit UI to screen** re-applies the best scale preset
- **Cleaner structure** — single project root (no nested duplicate folder)

## Project structure

```text
Android-LibTool-New/
├── app/
│   ├── build.gradle
│   └── src/main/
│       ├── jni/                 # Native C++ (ImGui menu + tools)
│       │   ├── Main.cpp         # Menu tabs, settings, draw loop
│       │   ├── Menu/
│       │   │   ├── ImGui.cpp      # EGL / OpenGL / input setup

│       │   ├── Tool/              # Feature tabs (Tools, Strings, Processes, …)

│       │   ├── imgui/             # Dear ImGui
```

Build artifacts (`app/src/main/obj/`, `app/src/main/libs/`, `app/build/`) are git-ignored and regenerated by ndk-build / Gradle.

## Build (AIDE / Gradle)

1. Open **`Android-LibTool-New`** in AIDE or Android Studio.
2. Build the APK (Gradle **assembleDebug** or AIDE build).
3. Install on device; inject / load `libTool.so` per your usual workflow.

Requirements: NDK, API 30+, ABIs `armeabi-v7a`, `arm64-v8a`, `x86`.

## Menu tabs

| Tab | Purpose |
|-----|---------|
| **Tools** | IL2CPP class browser, hooks, patches |
| **Tracer** | Live traced method hits (when hooks active) |
| **Strings** | In-memory string search |
| **Processes** | `/proc` process list + `/data/app/` `.so` maps |
| **So Monitor** | Dobby instrumentation on any loaded `.so` |
| **Dumper** | IL2CPP dump helpers |
| **Settings** | Scale, FPS, keyboard fix, app info |

## Processes tab

- `Tool/ProcessTab.h` / `Tool/ProcessTab.cpp` — PID list, filter, refresh
- Tap a process → shared libraries under `/data/app/` with map addresses and offsets
- Read-only view (mapping monitor removed in this build)

## So Monitor tab

- `Tool/SoMonitor.h` / `Tool/SoMonitor.cpp`
- Pick a loaded `.so`, convert runtime address ↔ offset, start/stop Dobby monitor
- **Clear log** / **Copy all** for the event table

## Settings — display tips

- **Scale** — manual override (Tiny … XL). Auto scale runs once on first open.
- **Auto-fit UI to screen** — re-run auto scale after rotating or changing resolution.
- **Fullscreen** — under **Tools** tab; expands menu to full display.
- **Show FPS counter** — overlay in top-right corner.
